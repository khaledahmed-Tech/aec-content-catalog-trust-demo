# Synthetic Data Guardrails

## Full disclaimer

Synthetic product prototype. Records and interactions are fictional metadata only. No design files, technical validation, software integration, or vendor affiliation.

The trust score is a synthetic indicator of catalog-record confidence. It is not a certification of design quality, engineering fitness, safety, constructability, file integrity, code compliance, standards compliance, or production readiness.

## Design disclaimer

This prototype uses a generic guided-learning and card-based product-demo structure. It is not affiliated with, endorsed by, or visually copied from Salesforce Trailhead, Salesforce Lightning Design System, Autodesk, or Autodesk Content Catalog.

## Data allowed

- Synthetic JSON fixtures.
- Fictional asset, request, warning, telemetry, and admin-review identifiers.
- Fictional teams, owners, standards, dates, tags, parameters, and usage counts.
- Plain-text software/version labels used only as metadata examples.
- Browser-local simulated state for requests, admin actions, audit entries, and demo reset behavior.

## Data and capabilities prohibited

- No real BIM data.
- No real Autodesk data.
- No real customer, project, person, company, or proprietary data.
- No RFA, DWG, model, drawing, project, or design files.
- No file upload, file download, file insertion, file parsing, file conversion, or file integrity checks.
- No real Revit or AutoCAD integration.
- No Autodesk APIs or external design-content services.
- No AI-generated design content or inferred engineering parameters.
- No production authentication, authorization, secrets, databases, analytics services, or personally identifiable information.

## Claims prohibited

- No claims of production validity or production readiness.
- No customer, adoption, revenue, performance, market, or usage claims outside the synthetic dataset.
- No safety, engineering, compliance, code, constructability, certification, file-integrity, interoperability, or design-quality claims.
- No claim that trust score validates BIM correctness or technical fitness.
- No claim that admin priority is an engineering, safety, compliance, or criticality score.
- No claim that telemetry is customer evidence.
- No claim that product opportunity cards make roadmap decisions.

## Branding prohibited

- No Autodesk logos, brand colors, screenshots, product claims, APIs, copied screens, trade dress, or implied affiliation.
- No Salesforce logos, Trailhead naming, mascots, badge graphics, Salesforce Lightning Design System components, copied screens, trade dress, or implied affiliation.
- No commercial catalog imitation or feature-for-feature reproduction.

## Review checklist for future UI and copy changes

Before merging a copy, UI, data, or logic change, confirm:

- The persistent synthetic-data disclaimer remains visible in the app shell.
- Trust-score explanations include the guardrail that the score is not certification.
- Compatibility copy says declared metadata only, not validated integration.
- Select-for-reuse copy says simulated event, not download, insert, or load.
- Request forms do not collect real project names, customer names, people, attachments, or proprietary details.
- Admin priority copy says product-priority aid, not safety or engineering criticality.
- Telemetry sections say synthetic telemetry and show definitions, denominators, and limitations.
- Opportunity cards say investigation prompt only, not automated roadmap decision.
- No new vendor branding, trade dress, logos, mascot metaphors, or copied interface patterns were introduced.
